## Summary

The client generates small FP8 integers with varying E8M0 scales, then verifies the dequantized values. It refuses unsupported element/scale formats, partial K blocks, padded input leading dimensions and multiple batches. Placement extends to the scale buffers, whose poison bytes decode to a tiny E8M0 value so an uncarried scale read affects the output.

Recomputing reference floats from the replaced bytes is essential: the generator's original reference describes different inputs. The independent byte-decoding assertion is the useful direct test of this contract.

At `projects/hipblaslt/clients/common/include/testing_matmul.hpp:2603`, preflight still counts each fast_check A/B copy in its one-byte FP8 storage type and omits the ordinary host operand in fast_check-only mode. No forced out-of-memory test was run, and the calculation remains preflight guidance rather than a memory reservation.
