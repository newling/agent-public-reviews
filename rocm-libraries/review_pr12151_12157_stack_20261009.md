## Summary

TensileLite is the Python code generator used to build hipBLASLt's matrix-multiplication kernels and their selection metadata. Its implementation historically lived under the Python package name `Tensile`. PR #12150 has already moved that implementation and its tests to `tensilelite`, while retaining a small `Tensile` package that redirects imports to the same implementation.

These seven follow-up PRs migrate the consumers of that package. Most edits change imports and mock targets in tests, for example:

```python
# Previous spelling
from Tensile.Common import globalParameters

# Preferred spelling
from tensilelite.Common import globalParameters
```

The shared-object behavior matters: these imports must refer to the same mutable settings, classes, and modules. Otherwise a test could patch one module while the code under test reads another. The submitted wheel passes checks for module identity, shared global parameters, shared mock targets, package resources, both import orders, and a serialized object using the old module spelling.
